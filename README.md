# 商品数据扫描（多平台商品采集）

基于 FastAPI + Playwright 的本地商品数据采集系统。前端提供淘宝、京东、拼多多、抖音、1688 五个接入平台菜单；支持提前扫码登录并保存登录态；按关键词与规格要求爬取商品数据；内置**智能优惠监控**（降价/促销/优惠券/0元购）与**价格历史追踪**，数据列展示当前价、优惠后价、优惠金额、历史低价、库存等完整信息。

## 功能状态

| 平台 | 菜单 | 登录态 | 搜索采集 | 说明 |
|------|------|--------|----------|------|
| 淘宝 | ✅ | ✅ | ✅ | 支持天猫商品链接 |
| 京东 | ✅ | ✅ | ✅ | 搜索页 `search.jd.com` |
| 拼多多 | ✅ | ✅ | ✅ | 移动端搜索页，通用卡片解析 |
| 抖音 | ✅ | ✅ | ✅ | 搜索页商品卡片 + 视频商品 |
| 1688 | ✅ | ✅ | ✅ | offer 搜索页，批发字段解析 |

> 五个平台均可提前登录（各自独立的持久化浏览器配置目录），采集适配器全部可用。新增三个平台共用 `generic.py` 的卡片解析 + 链接锚点回退 + 页面 JSON 兜底三级策略；页面类名改版时只需调整对应平台的配置，不必改解析逻辑。
>
> **五个平台的搜索结果均需要登录后才能查看**：请先完成对应平台的「提前登录」，再执行搜索。未登录时系统会直接提示需要先登录，不会返回空列表。

## 智能优惠监控（v2.1）

左侧「功能区 → 优惠监控」进入，包含两块：

### 监控任务
- 新建任务：选平台 + 关键词 + 轮询间隔（≥60 秒，建议 ≥300 秒）+ 可选规格词。
- 后台调度器自动轮询，复用限流守卫（节流/冷却），不会因监控触发平台封禁。
- 支持暂停/启动/删除，显示运行状态、运行次数、上次运行时间和错误信息。

### 告警消息
后台分析每次采集结果，自动识别并落库：

| 告警类型 | 触发条件 |
|----------|----------|
| `price_drop` 降价 | 当前价低于上次采集价 |
| `low_price` 历史低价 | 触及本地价格库历史最低 |
| `coupon` 优惠券 | 识别到券/满减/红包 |
| `promo` 促销 | 秒杀/补贴/限时/直降 |
| `free_trial` 0元试用 / `free_buy` 0元购 | 识别到免费/0元关键词 |

页面顶栏显示未读优惠数，点击可跳转；告警每 15 秒自动刷新，支持全部已读/清空。

### 价格历史
每次采集的商品价格写入 SQLite（`data/store.db`）。数据列表展示：

- **当前价 / 划线价**（划线价灰色删除线）
- **优惠后价**（券后价、补贴价，红色高亮）
- **优惠金额**（划线价 − 到手价）
- **历史低价**（本地采集库最低价）
- **库存**（可解析时显示件数）
- **优惠类型标签**（降价/促销/优惠券/0元购，不同颜色）

查询接口：`GET /api/products/{platform}/{sku}/history` 返回价格区间与时间序列。

## 安装与启动

```bash
pip install -r requirements.txt
python -m playwright install chromium   # 首次使用需要下载浏览器内核
python run.py
```

浏览器打开 <http://127.0.0.1:8765>。

如果本机已安装 Chrome / Edge，可跳过下载内核：程序会依次尝试内置 Chromium、系统 Edge、系统 Chrome，哪个可用就用哪个。也可强制指定：

```bash
# Windows 示例
set BROWSER_CHANNEL=msedge
python run.py
```

## 使用流程

1. **提前登录**：左侧选择平台 → 点击「提前登录」→ 在弹出的浏览器窗口中扫码或账号登录 → 系统自动检测并提示登录成功。登录态写入 `data/profiles/<平台ID>/`，下次直接复用。
2. **搜索商品**：填写关键词后，页面会按所选平台动态展示该平台的专属筛选条件——**全部为下拉选择，无需输入**。点击「搜索商品」。平台条件会拼入搜索 URL，并在结果端做本地兜底过滤与排序。
   - **各平台真实分类体系（两级联动下拉）**：一级分类按各平台实际类目配置（京东 17 类、淘宝 12 类、拼多多 9 类、抖音 8 类、1688 10 类），选中一级后二级自动列出常见子分类（如「电脑/办公/文具 → 笔记本/显示器/CPU…」）。选中的分类作为关键词附加词拼入搜索 URL 提升精准度。
   - **全部选择式筛选**：价格区间（¥0-50 ~ ¥10000 以上，下拉）、排序方式、配送/店铺、活动类型、发货地等均为单选下拉；热门品牌、服务特色、供应商类型为**下拉多选勾选**（展开面板逐项勾选，显示已选数量）。起订量（1688）也改为下拉。
   - 保留两个自由输入项：**搜索关键词**（搜索目标）与**规格/要求**（本地命中词，多个词需全部命中）——这两项是搜索内容本身，无法穷举为选项。平台侧筛选条件已全部选择化。
   - **抓取页数不设上限**：`pages` 可填任意正整数（1、5、20、50…），按平台实际可翻页数采集。
   - **最大条数可不限**：`max_results` 填 `0` 或留空表示不限制返回条数；填正整数则最多返回该条数。
3. **查看数据**：结果表格支持固定表头 + 滚动表体；点击「查看商品」在新标签页打开商品链接；可导出 CSV。
4. **维护登录态**：「刷新登录态」重新检测，「清除登录态」删除该平台的浏览器配置，下次需要重新登录。

搜索请求示例：

```json
{
  "platform": "jd",
  "keyword": "笔记本",
  "specs": "32G内存 1T硬盘",
  "filters": {
    "price_range": "3000-5000",
    "category": "电脑/办公/文具",
    "category_sub": "笔记本",
    "sort": "sort_totalsales15_desc",
    "channel": "self",
    "brand": "ThinkPad,联想",
    "service": "自营,优惠券"
  },
  "pages": 1,
  "max_results": 0
}
```

> 筛选条件全部为选择式取值：`price_range` 为价格区间、`category`/`category_sub` 为两级分类、`brand`/`service` 为逗号拼接的多选值。`pages` 无上限；`max_results` 为 `0`（或省略）表示不限制返回条数。前端「抓取页数」留空默认 1，「最大条数」留空或 0 即不限。

## 扩展新平台

1. 在 `app/config.py` 的 `PLATFORMS` 追加平台定义（登录/首页/搜索 URL、登录态选择器）。
2. 在 `app/crawlers/` 新建适配器，继承 `BaseCrawler`，实现 `prepare()` 与 `extract()`。
3. 在 `app/crawlers/registry.py` 注册平台 ID → 适配器类，并把 `enabled` 改为 `True`。

## 限流处理（重要）

京东等平台会对高频搜索的出口 IP 临时限流，页面显示「抱歉由于访问频繁导致无法搜索」。这与是否登录无关。

系统内置三层防护（`app/guard.py`）：

1. **节流**：同一平台两次真实请求间隔至少 8 秒，翻页间隔 3 秒。
2. **渐进式冷却**：一旦检测到限流，按连续触发次数指数级延长冷却——首次 3 分钟、再次 6 分钟、12 分钟……上限 30 分钟，期间直接返回 HTTP 429 和剩余秒数，不再发请求（避免延长封禁）。采集成功一次后计数清零。
3. **缓存**：相同关键词+条件（含页数）的结果缓存 10 分钟，重复搜索直接返回，不触发真实请求。

应对措施（按优先级）：

- **等待**：按提示等待冷却结束，期间不要反复点搜索。
- **查状态**：`GET /api/platforms/{id}/cooldown` 查看剩余秒数。
- **换出口 IP**（已验证有效）：在**启动命令前**设置代理环境变量后重启：

  ```bash
  # Windows Git Bash / PowerShell
  SEARCH_PROXY=http://127.0.0.1:65202 python run.py
  ```

  > 注意：代理必须在**进程启动前**通过命令行前缀设置。因为 `config.py` 在 import 时读取 `SEARCH_PROXY`，在 `run.py` 内部再 `os.environ` 赋值不会生效。
  > 换代理出口后，京东会要求**重新扫码登录**（登录 cookie 绑定原 IP/账号）。可运行 `python login_jd_proxy.py` 弹出有头浏览器扫码，登录态存到 `data/profiles/jd_proxy_login`，验证通过后可替换 `data/profiles/jd` 供采集复用。

- **手动解除**：确认限流已过时 `POST /api/platforms/{id}/cooldown/reset`。

### 已验证结论（2026-11-26）

代理模式 + 重新扫码登录后可正常采集京东真实数据（8 条商品 / 17 秒）。京东搜索页展示的**当前价即到手价**，划线价为原价，优惠额 = 划线价 − 当前价；已从标签误解析中修复该逻辑。

## 说明与限制

- 登录态与搜索历史仅保存在本机，不上传任何服务器。
- 电商平台的页面结构与反爬策略经常变化：若采集结果为 0，请先确认已登录，再检查适配器选择器是否需要更新。
- 本工具仅用于个人合法的数据整理场景，请遵守各平台的服务条款与 robots 约定，控制采集频率。
